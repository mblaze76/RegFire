API connection

A supported JSON adapter, configured on your server.

POST JSON containing member_id and email. Response: {"member": {...}} or {"member": null}. HTTPS port 443 only. No redirects or private network targets. Use fixture://demo for synthetic local tests.

Enter the variable name only, never a token. Set its value securely in the server environment before launch. No credential value is sent to this browser.
