# LinkedIn button asset

`static/linkedin-in-official.png` is the unmodified `LI-In-Bug.png` from LinkedIn's official [download page](https://brand.linkedin.com/downloads), downloaded October 10, 2026 from:

https://content.linkedin.com/content/dam/me/business/en-us/amp/xbu/linkedin-revised-brand-guidelines/logos/in-logo.zip

Displayed in its original blue on white, with preserved aspect ratio and 21px height. See the [official logo guidelines](https://brand.linkedin.com/in-logo). The label is “Register with LinkedIn” as requested; the existing action remains consent-based autofill of empty profile fields, not RegFire sign-in or completed registration. Provider configuration is still required.
